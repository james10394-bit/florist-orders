# 隅花相識 Amor Flores Design｜照片上傳後台＋顧客預訂 v2.3.0

`index.html` 是精品花店顧客端，`admin.html` 是雲端後台入口，`offline-admin.html` 保留原本的離線訂單工具。顧客端支援現成商品與客製花禮、手機預訂、配送資料與卡片文字，並可透過 Google Apps Script 後端寫入 Google 試算表及專用行事曆。

## 串接 Google 試算表與行事曆

1. 到 `https://script.google.com/` 建立新專案，把 `flower-orders-backend.gs` 的完整內容貼入 `Code.gs`。
2. 選擇 `setupFlowerBackend` 並執行一次，完成 Google 權限授權。
3. 點「部署 → 新增部署 → 網頁應用程式」，執行身分選「我」，存取權選「任何人」。
4. 複製部署後以 `/exec` 結尾的網址。
5. 編輯 `config.js`，把網址貼入 `orderApi` 的引號內。
6. 把執行記錄顯示的試算表網址貼入 `config.js` 的 `adminSheetUrl`，再上傳更新到 GitHub。

正式接單前請自己送出一筆測試訂單，確認試算表有新增資料，且「隅花相識｜顧客預訂」日曆出現 `[待確認]` 事件。

## 手機、Windows PC 與 Mac 同步

- 訂單送出時會立即寫入 Google 試算表與「隅花相識｜顧客預訂」日曆，不需等待排程。
- 手機安裝 Google 試算表及 Google 日曆並登入建立後端時使用的同一帳號。
- Windows PC 直接使用瀏覽器開啟 Google 試算表與 Google 日曆。
- Mac 可使用瀏覽器；若要在 Apple「行事曆」查看，請在 macOS 的「系統設定 → 網路帳號 → Google」開啟行事曆同步。
- Google 服務會自行同步，通常數秒內可見；若手機未立即顯示，可在行事曆畫面下拉重新整理。
- 跨裝置訂單與商品以 Google 試算表及 Google 日曆為準；`offline-admin.html` 只供無網路時備用，不會跨裝置同步。

## 雲端商品後台

- `admin.html` 是雲端後台入口；原本的本機工具已移到 `offline-admin.html`。
- Google 試算表的「商品」分頁可修改：上架、排序、商品名稱、副標、價格、分類、圖片網址及按鈕文字。
- 「上架」使用核取方塊；取消勾選後，網站下一次更新時會隱藏商品。
- 分類可填：生日、告白／紀念、開幕、日常；多個分類用頓號分隔。
- 圖片網址須為公開的 HTTPS 網址。Google Drive 圖片可貼分享網址，但分享權限必須設為「知道連結的任何人都可查看」。
- 商品資料公開給顧客網站讀取，但訂單與顧客資料仍保留在私人試算表中。
- 網站每 2 分鐘讀取一次商品；後端快取最長 60 秒，重新整理網頁即可再次載入。

## 後台直接上傳照片（v2.3）

1. 將新版 `flower-orders-backend.gs` 完整貼回原本的 Apps Script 專案並儲存。
2. 在函式選單選擇 `setupPhotoUpload`，執行一次並完成 Google Drive 權限授權。
3. 從執行記錄複製「管理金鑰」並安全保存；不要把金鑰貼進公開 GitHub。
4. 以「部署 → 管理部署作業 → 編輯 → 新版本」更新原本的網頁應用程式，原 `/exec` 網址保持不變。
5. 更新 GitHub 的 `admin.html`，開啟 `admin.html` 後輸入管理金鑰、選擇商品與照片，即可上傳並自動更新商品圖片。

照片會存入 Google Drive 的「隅花相識｜商品照片」資料夾。支援 JPG、PNG、WebP、HEIC、HEIF，單張上限 8 MB。管理金鑰只保存在目前瀏覽器分頁；若金鑰外洩，請在 Apps Script 執行 `rotatePhotoUploadKey`，舊金鑰會立即失效。

## 功能

- 建立、編輯、搜尋、篩選訂單；月曆查看每天的交付量，點日期查看該日訂單。
- 訂購人與收件人資料分開記錄；品項、數量、價格、配送費、折扣、製作日期、交付日期與時段、卡片、客製需求、來源、狀態及付款資料。
- 配送單要求收件人姓名、電話、地址；檢查製作日期與金額；排除已取消訂單的日曆事件。
- 單筆「加入 Google 日曆」開啟確認頁，需使用者在 Google 日曆儲存；單筆或全數下載 `.ics`，可匯入 Apple Calendar、Outlook 等。
- JSON 備份與還原；匯入會先確認，再覆蓋現有資料。

## 儲存與日曆限制

訂單存於**目前瀏覽器的 localStorage**。GitHub Pages 僅提供靜態頁面，沒有帳號、多裝置同步或伺服器資料庫；清除網站資料、無痕模式結束或更換手機可能讓資料消失。請定期下載 JSON 備份並安全保管，勿將含客戶電話和地址的備份提交至公開儲存庫。公開網址只公開程式，**不會公開本機已填的訂單**。日曆連結與 `.ics` 包含客戶資料，分享或匯入前請確認日曆的可見範圍。Google 日曆按鈕是建立事件草稿，並非雙向同步；編輯或刪除訂單後，已加入外部日曆的事件需自行更新。

日曆事件以台灣時區、預設時段產生；「指定時間」以 09:00–10:00 佔位，實際指定時間請在日曆中調整。製作日期目前僅供訂單追蹤，月曆按交付日期展示。

## 日後擴充

多人共同使用時，需增加登入、權限、資料庫、備份及真正的 Google Calendar OAuth 同步，靜態版不適合做多人共享訂單。
